How to use this
  1. Open the .xlf file you were sent (or drag it onto this page). Nothing is uploaded: the file stays on your computer.
  2. Type your translation in the box next to each English line. Page layout code is hidden from you and put back automatically.
  3. Some lines contain small orange markers like 1…/1. They mark a link or bold text. Keep the markers in your translation, around the words that should be linked or bold. Click a marker on the English side to insert it.
  4. Your work is saved in this browser as you type. When you are done, press Download translated file and send that file back.

Tip: Ctrl + Enter (⌘ + Enter on Mac) jumps to the next line that still needs translating.
